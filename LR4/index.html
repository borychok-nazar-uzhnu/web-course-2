Основи CSS: Селектори, стилі та магія оформлення

Що таке CSS?

CSS (Cascading Style Sheets) — це мова, яка дозволяє оформлювати вигляд HTML-документів. Вона контролює кольори, шрифти, відступи, розміщення елементів і навіть анімації.

Типи підключення CSS

  • Зовнішній файл — <link rel="stylesheet" href="styles.css">
  • Вбудований — у межах тегу <style>
  • Inline — безпосередньо в атрибуті style

Комбінуючи різні способи підключення, можна досягти найкращого контролю над виглядом сторінки.
